How it works

Two hooks and one cheap question.

Runs on every prompt. You never call it.

You type

Small contexts, slash commands and follow-ups like “fix it” pass straight through.

Haiku judges

Above 20k tokens, one isolated question: new task? Unsure means same. About $0.0013 and 3.5s.

Archive and clear

Old chat saved on your machine, your prompt saved, /clear typed for you.

Task starts

Prompt restored with up to 5 key facts from the old work. Claude gets going.

FAQ

Good questions.

Something else? Open an issue.

Will it clear something I still needed?

Rarely: 0 wrong switches in the latest 64 test prompts, and the judge answers “same” when unsure. If it happens, the old chat is archived and /ghosted:recall finds it. Start a prompt with same: to block a switch, or new: to force one.

Is my code sent anywhere?

Only to Claude, through your own claude login, for the judge question. Archives stay on your machine, readable only by you. No telemetry, no accounts, no server.

Why clear instead of compact?

A compact summary still carries a lot of old text and costs a model call to write. Clearing with a few carried facts saved 70%; compacting saved 34%. Prefer compact? Set GHOSTED_MODE=compact.

Which terminals does it work in?

Everywhere Claude Code runs. In macOS Terminal.app and Windows consoles it types the commands for you. In iTerm, tmux, VS Code and Linux terminals it tells you which command to run, then you type go.

Can I tune or pause it?

/ghosted pause, /ghosted stats, /ghosted full|lite|off for terse answers, /ghosted max 250k for long runs. Settings also live in /config.
