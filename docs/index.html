Claude Code plugin · open source

Stop paying for context you no longer need.

When you start a new task, ghosted_ clears the old conversation and starts your task for you. Same typing. A fraction of the bill.

$ claude plugin marketplace add giovanbelle/ghosted
$ claude plugin install ghosted@ghosted

The problem

Claude Code only compacts when the context is nearly full. Until then, finished work rides along on every message.
