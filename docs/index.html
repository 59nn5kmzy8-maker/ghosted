Stop paying for context you no longer need.

The problem in one picture

Every turn re-sends the whole context.

Claude Code only compacts when the context is nearly full. Switch task before then, and the old work rides along on every message.

What happens

Three steps. Zero commands.

It notices

A small Haiku judge asks one question: is this prompt a new task? Follow-ups never trigger it.

It clears

The old chat is archived on your machine, then /clear is typed for you.

It restarts

Your prompt comes back with up to 5 useful facts, and Claude starts on it.

Install in 30 seconds.

Two commands, then restart Claude Code. Apache-2.0, zero dependencies, works on macOS, Windows and Linux.
