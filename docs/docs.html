Set up once. Then forget it.

Needs Node.js and the claude CLI on your PATH. Cache warming also uses python3. No other dependencies.

Install

Add the marketplace

claude plugin marketplace add giovanbelle/ghosted

Install the plugin

claude plugin install ghosted@ghosted

Restart Claude Code

You'll be asked for three settings. The defaults are fine.

Remove the plugin: claude plugin uninstall ghosted@ghosted

Delete its archives and stats: remove ~/.claude/plugins/data/ghosted-ghosted. Nothing is stored anywhere else.

FAQ

Will it clear something I still needed?

Rarely: 0 wrong switches in the latest 64 test prompts, and the judge answers “same” when unsure. If it happens, the old chat is archived and /ghosted:recall finds it. Start a prompt with same: to block a switch.

Do I need to run anything after installing?

No. It runs through Claude Code hooks on every prompt. The commands are only for tuning.

Why clear instead of compact?

A compact summary still carries a lot of old text and costs a model call to write. Clearing with a few carried facts saved 70%; compacting saved 34%.

I already use caveman. Do I need both?

They stack: $3.32 per run with caveman alone, $0.92 with ghosted_ added. ghosted_'s own terse mode steps aside while caveman is active.

What does cache warming cost?

Each ping reads the context from cache at a tenth of the input price, about once an hour on subscriptions. It stops before the pings cost half of the full cache rewrite you'd pay coming back cold, and immediately if one ever misses the cache. /ghosted stats shows every ping.

Nothing happened after “new task detected”.

Your terminal doesn't support auto-typing, or macOS automation permission was declined. Run /clear, then type go. Your task is saved and comes back.
