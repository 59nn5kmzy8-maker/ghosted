Legal

Plain-language legal.

ghosted_ is free, open-source software that runs on your own computer. There is no account, no server and no data collection.

Last updated 29 October 2026

Privacy notice

In short: the author of ghosted_ receives none of your data. The plugin stores its files on your computer, and the only thing it sends anywhere is a short excerpt to Claude, through your own Claude Code login, when it needs to decide whether you started a new task.

What the plugin processes

  • Task-switch check. When your context is above the threshold and a prompt isn't an obvious follow-up, ghosted_ sends Anthropic's Claude Haiku model the start of the conversation (up to 2,000 characters), its end (up to 6,000 characters) and your new prompt (up to 4,000 characters). It runs through the claude command-line tool you are already signed in to, so Anthropic processes this under your own agreement with Anthropic and Anthropic's privacy policy.
  • Cache warming. While your session is idle, ghosted_ re-sends it to Claude through a hidden copy of the session, so Anthropic's prompt cache stays warm. This sends the same conversation Claude Code already sent, under the same login. The copy's transcript is deleted right after. Turn it off with /ghosted warm off.
  • Archive. When the context is cleared, the old conversation is saved to ~/.claude/plugins/data/ghosted-ghosted on your computer, with file permissions that let only your user account read it.
  • Stats and settings. Counts of task switches and judge costs, and the settings you choose with /ghosted, are stored in the same folder.

What the plugin does not do

  • No telemetry, analytics, tracking or crash reporting.
  • No connection to any server run by the author.
  • No selling or sharing of data, because the author has none.

Your control

Pause the plugin with /ghosted pause, or set GHOSTED_OFF=1. Delete everything it stored by removing the folder above. Uninstall with claude plugin uninstall ghosted@ghosted. Because the author holds no personal data about you, there is nothing to request, correct or delete from the author.

This website

The site is hosted on GitHub Pages. GitHub may log technical data such as your IP address when you visit; see GitHub's privacy statement. The page asks the public GitHub API for the repository's star count from your browser. The site sets no cookies and runs no analytics.
