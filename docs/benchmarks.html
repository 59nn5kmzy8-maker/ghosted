Where it doesn't help

One long task, no switch

Nothing to clear, so nothing saved. ghosted_ stays out of the way.

Mid-run compaction

In single runs it cost more ($8.61 vs $9.73), because files get read again. That's why it's off by default.

A wrong switch

Once, before the judge fix, a follow-up was judged new and the work was lost. Since then: 0 in 64, and same: blocks it.
